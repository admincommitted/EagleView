    How it works
    1. Open ICEGATE login and log in yourself (ID, password, CAPTCHA). The tool keeps you there only as long as ICEGATE does - when ICEGATE warns that the session ends, the ICEGATE window comes to the front and you answer it.
    2. Tick up to 5 documents of one job (one DRN) and press Start batch.
    3. Open the e-Sanchit upload page and press Put the files in ICEGATE - the files go in and Upload is pressed.
    4. For each file press Fill details; the filled fields on ICEGATE are marked blue.
    5. Check everything and press Submit on ICEGATE yourself. The IRN / DRN come back and are saved on the job.

    Sign files

    A PDF is saved next to it as name_signed.pdf (ready for e-Sanchit). Any other file gets a name.sig (signed envelope with the file inside).

    Choose the files to sign. Nothing is uploaded - the signed copies stay in the same folder.
